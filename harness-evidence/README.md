# 赛题二 loss_decoder Harness · 逐组证据版

本版本从 `harness-optimized` 延伸。正式演化仍由官方外层评估器计量，默认从同一份官方初始程序先试解码器、再试损失函数。每轮包含三个训练算例和三个种子。只按官方完整矩阵选最终候选；同分时可用已发布的 TNS 改善率区分。

- 首轮回执直接进入第二轮提案、备选和复核。九组反馈按实际父版本和已发布的官方初始测量比较，缺失和失败组保留。WNS、TNS 和计分下限分别显示。
- 分层诊断区分实际换层和整体翻转后剩余差异。对实际父版本，仅在两份公开产物能逐实例对齐时计算；若对照官方起点只有计数而没有核实分母，翻转后变化留空。分层相同而时序变动会标记归因待核。
- 定向修补保留多数种子已有的收益。多数分层和时序同时不变且没有提分时换机制；只有时序证据时明确标注其来源。对与同一父版本下已证实无效的候选重复结构的提案，反馈原因并在送评前改方向。
- 本次运行的历史记录改动组件、结构、预测及反证；相关实验优先匹配失败阶段或同机制，再匹配算例和种子。提交日志保存选定候选的模型调用 ID，可对照模型实际收到的证据和生成代码。
- 初始提示的离线专家知识为 159 个计数单位，只随本次运行首个模型请求发送；不引用其他运行的候选或得分。

`program.py` 是任务包的官方初始算法。正式运行结束后，官方选中的候选 ID 对应新算法；公开验证应使用该 ID，不应修改算法。需保留物理交付文件时使用 `--retain-physical-files`。

离线入口（在本项目根目录运行）：

```powershell
python -B -m unittest discover -s harness-evidence/tests -v
```

测试用官方校验器、Agent 接口和计分函数配合模拟回执，验证第二候选读取首轮证据、前两轮单组件约束、调用追踪和最终选优。实际提分和耗时需要 GPU 对照确认。
