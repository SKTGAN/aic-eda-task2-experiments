# 赛题二的候选对照模板

这个目录为现有 `loss_decoder` Agent 补充一个候选对照模块。它读取同一次正式运行中父候选和子候选的官方评估反馈，按同一个算例、同一个种子比较时序和得分。模型能看到改善集中在哪些组、哪些组退步，以及割网指标和最终时序是否一致。

`agent-paired-feedback.patch` 可应用到现有 `loss_decoder` Agent 的独立副本。在副本的 `loss_decoder` 目录运行 `git apply --check /path/to/agent-paired-feedback.patch`，然后用 `git apply` 应用补丁，并复制 `paired_feedback.py` 到同一目录。下一轮模型请求会在每条候选反馈里附上 `parent_comparison`。Agent 续跑时读取 `search.jsonl` 中的父候选 ID，再从评估器取原有回执。官方起点没有对应回执时，仅提示父回执不可用。最终选优使用官方完整矩阵得分和既有同分规则。

- 完整矩阵才展示官方总分差。部分回执仍展示有分数的配对格子，同时按算例和种子标出缺失或未出分的组。评估器已确认的无效组仍保留其得分和原因。
- 每个格子同时展示 WNS、TNS、割网数量和时序加权割网的变化。官方回执提供归一化改善率时，也显示它们的差值，便于比较不同算例对分数的影响。选优以官方得分为准。
- 显示逐组分差的中位数、最大提升和最大退步，让 Agent 看出平均分是否被少数格子拉动。这些统计用于定位问题。
- 正式 Agent 使用当次运行的官方反馈。`experiments/`、本地报告和 `replay_feedback.py` 用于开发验证，放在提交目录之外。离线专家经验如需注入，按赛题要求集中声明在初始提示词中。

在当前工作区可用实际九组诊断记录回放：

```powershell
python -B E:/ide/aic-eda-task2/harness-feedback-template/replay_feedback.py E:/ide/aic-eda-task2/official/contest-work/hard-negative-three-case-summary.json
```

回放匹配了九组，平均改善 16.55 分，五组改善、四组退步。它能标记 WNS 改善而 TNS 退步，以及割网减少而得分下降的情况。

在当前 Windows 工作区，可用已有 Ubuntu WSL 环境验证接入。`smoke_agent.py` 在临时目录应用补丁，运行真实 `Agent.run`，用本地九组时序数据和模拟评估回执检查下一轮请求、部分失败、日志截断后的续跑和最终选优。它无需 GPU 或模型 API。Windows 原生 Python 可运行单独的 `replay_feedback.py`，完整 Agent 回放需先具备官方 Python 依赖。

```powershell

```

### 按训练轮数渐增负样本惩罚

渐增版只改权重生效的时间，整段训练的平均权重仍为 0.125。两组都跑完了 50 个 GNN epoch 和布局后的物理时序评估。

| `bp_fe-ng45` 种子 | 初始版 | 固定 0.25 | 固定 0.125 | 渐增版 |
|---|---:|---:|---:|---:|
| [1001](experiments/bp-fe-ng45-1001-ramped-comparison.json) | 15.77 | 50.46 | 37.33 | 30.59 |
| [1003](experiments/bp-fe-ng45-1003-ramped-comparison.json) | 55.91 | 54.10 | 46.83 | 49.57 |

相比固定 0.125，渐增版在种子 1001 掉分，在 1003 提分。两个种子都低于固定 0.25。这组结果未支持把渐增策略用作默认设定。种子 1001 首次运行因队列回执过期而失败，表中使用新日志已验证的重跑结果。

### 保留分组并交换顶层和底层

互换版保留初始损失和解码器产生的分组，在输出时交换两个分组所属的层。三个种子均完成布局和时序评估。逐组比对初始版和互换版，嵌入文件完全相同，25,847 个实例全部交换了层，跨层网的 ID 和时序加权割网均相同。

| `bp_fe-ng45` 种子 | 相同的跨层网数 | 初始版 | 互换版 | 分差 |
|---|---:|---:|---:|---:|
| [1001](experiments/bp-fe-ng45-1001-flipped-comparison.json) | 3,430 | 15.77 | 52.65 | +36.88 |
| [1002](experiments/bp-fe-ng45-1002-flipped-comparison.json) | 3,738 | 50.73 | 55.38 | +4.66 |
| [1003](experiments/bp-fe-ng45-1003-flipped-comparison.json) | 3,102 | 55.91 | 57.39 | +1.48 |
| **三组均分** | | **40.80** | **55.14** | **+14.34** |

三个种子的 WNS 都改善，1003 的 TNS 退步了 9.41 ns。互换在初始底层超节点较多的 1002 和初始顶层超节点较多的 1001、1003 都提分，目前还无法用超节点数量判断哪个方向更好。

`ariane133-ng45 / 1001` 的跨算例补测从 37.69 提到 41.11 分。训练嵌入相同，解码输出完整互换，官方可行性闭合让最终 131,550 个实例中的 4 个没有随另一组互换。最终割网增加 4 条。WNS 从 −0.732 ns 改善到 −0.594 ns，TNS 从 −11.19 ns 退步到 −22.44 ns。[大算例换层对照](experiments/ariane133-ng45-1001-flipped-comparison.json)

`bp-ng45 / 1001` 从 −38.95 提到 −19.42 分。训练嵌入相同，可行性闭合后有 1 个实例未互换。两版都是 5,877 条跨层网，但网的 ID 集合略有变化。两次跨算例补测加上小算例三组共五组，互换版五组均提分，样本内平均 +13.19 分。这些运行尚未覆盖 `bp-ng45` 和 `ariane133-ng45` 的另外四个种子组合。[`bp-ng45` 换层对照](experiments/bp-ng45-1001-flipped-comparison.json)

### 固定负样本惩罚与换层的组合

`bp_fe-ng45 / 1001` 上，初始版得 15.77，单独固定惩罚得 50.46，单独换层得 52.65，组合版得 28.37。组合版和单独惩罚版的训练嵌入及加权割网相同，但换层使 WNS 和 TNS 均退步。两项单独改动的收益在这个种子上没有叠加。组合首次因并行运行时 WSL 可用内存不足而未完成后端，正式对照采用随后单独重跑的成功记录。[组合版对照](experiments/bp-fe-ng45-1001-hard-negative-flipped-comparison.json)

当前优先验证 `flipped_layer_decoder.py` 的剩余四个训练组合。初始损失加互换解码器保留为单独候选，等完整矩阵反馈再判断是否胜过其他候选。实验候选及回执均用于本地验证。

### 只用超出单位权重的部分拉近星边

新损失把网线权重超过单位权重的部分分配给该网的星边，再用总超额权重归一化。解码器沿用官方实现。`bp_fe-ng45 / 1003` 的 1 倍和 4 倍版都通过完整物理流程。两版的嵌入文件均相对初始版发生变化，解码输出、最终分层和跨层网文件逐字节相同，得分、WNS 和 TNS 都与初始版完全一致。

| `bp_fe-ng45 / 1003` | 得分 | WNS（ns） | TNS（ns） | 最终割网 |
|---|---:|---:|---:|---:|
| 初始版 | 55.91 | −0.664914 | −173.788540 | 3,102 |
| 旧全边拉近 4 倍 | 43.09 | −0.726340 | −294.331991 | 3,103 |
| [超额权重 1 倍](experiments/bp-fe-ng45-1003-criticality-excess-affinity-comparison.json) | 55.91 | −0.664914 | −173.788540 | 3,102 |
| [超额权重 4 倍](experiments/bp-fe-ng45-1003-criticality-excess-affinity-4x-comparison.json) | 55.91 | −0.664914 | −173.788540 | 3,102 |

4 倍版的原始聚类诊断割网从 1,377 减至 1,367，实际解码输出相同。超额权重的方案在这一组避免了旧 4 倍方案的时序退步，未验证出高于初始版的收益。4 倍版首次被 WSL 可用内存检查拦下，表中使用 6 GiB 原配置重跑的完整结果。
