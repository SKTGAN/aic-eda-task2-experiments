# Harness 单因素对照版

从 Claude 第三版分出，适用 `loss_decoder`。遇到首轮损失改动大多被抵消，或最近一次与本轮实测父版本的比较同时出现多组收益和一组明显退步时，最多安排两次单因素试验。候选保留一个组件，围绕另一个组件里的一个机制修改。父候选已有回执，直接用作对照。

每次试验仍跑完整九组。模型收到要修的算例和种子、需要保住的收益、WNS/TNS、切割及分层证据。算例和种子只用于描述观测，算法本身不能按算例或种子分支。与发布初始值比较时排除分层相同的组作为保护或修补目标。验收一律对比本轮已有的实测父候选。

当前开发阈值为 2 分。非开局的修补要求至少两组各提高 2 分，且最差一组占所有下降分差的至少 65%。试验验收时，目标组至少提高 2 分，任何受保护组和任何算例的均分最多退 2 分，九组总均分不得下降。通过就沿试验结果继续，失败或未核实就回到实测对照。现有最终选优规则保持原样。回放结果只说明 Harness 如何选下一步，实际增益由物理评估验证。

```powershell
python -X utf8 -B -m unittest discover -s tests -v
```
